# Plot Method for dynarules_perm

Observed lift against the permutation-null mean per rule; significant
rules (adjusted p \< .05) are highlighted.

## Usage

``` r
# S3 method for class 'dynarules_perm'
plot(x, top = 20L, ...)
```

## Arguments

- x:

  A `dynarules_perm` object.

- top:

  Integer. Plot the top N rules by adjusted p. Default 20.

- ...:

  Ignored.

## Value

A `ggplot` object, invisibly.
