# Summary Method for dyna_transactions

Summary Method for dyna_transactions

## Usage

``` r
# S3 method for class 'dyna_transactions'
summary(object, ...)
```

## Arguments

- object:

  A `dyna_transactions` object.

- ...:

  Ignored.

## Value

A tidy data.frame with one row per item: its support (fraction of
transactions containing it) and count.
